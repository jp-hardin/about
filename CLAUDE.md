# Notes for Claude Code

- Site pages under `mid-market-practice/` are generated by `mid-market-practice/_build/build.py`. Edit the script and rerun it; do not hand-edit the generated HTML.
- Sector reports live in `mid-market-practice/insights/` as `<industry>-industry-report-q<N>-<year>.html/.pdf` and are generated from `mid-market-practice/_build/reports/<report>/`. See the README in each report folder for the rebuild command. List each report in `INSIGHTS` in `_build/build.py`; the newest per industry is shown as Current on `insights/index.html` and older ones move to the archive. `reports/` only holds redirects from the old URLs.
- Merging to `main` publishes the live site through GitHub Pages.
