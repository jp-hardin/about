# Notes for Claude Code

- Site pages under `mid-market-practice/` are generated by `mid-market-practice/_build/build.py`. Edit the script and rerun it; do not hand-edit the generated HTML.
- Industry reports live in `mid-market-practice/insights/` as `<industry>-industry-report-q<N>-<year>.html/.pdf` and are generated from `mid-market-practice/_build/reports/<report>/`. See the README in each report folder for the rebuild command. All five (Industrial, Business Services, Consumer, Healthcare and Technology) are built from the PowerPoint report deck in the folder (`brief.pptx`, the authoritative source) by `_build/reports/brief.py`, so the PDF and the page always match: change the deck and rerun `sh build.sh`, never the generated page. The site's top level is Industries (the five above, under `industries/`); the level below is Sectors. `REPORTS_LIVE` in `_build/build.py` switches the reports on or off; while False it hides the Insights page, report pages, PDFs and every link to them (and the report builder refuses to run without `--preview`). The Q4 2026 decks are the final versions with the house fixes applied in the deck itself (Jordan's transaction wording, Industrials, Middle Market, serial commas, Jason Lisiak, CFA, the valuations disclosure line, logo alt text), so the deck, PDF and page match. Each report page also gets FAQs taken from the deck's own headlines (`faq.json`, also used in `llms-full.txt`). List each report in `INSIGHTS` in `_build/build.py`; the newest per industry is shown as Current on `insights/index.html` and older ones move to the archive. `reports/` only holds redirects from the old URLs.
- Merging to `main` publishes the live site through GitHub Pages.
