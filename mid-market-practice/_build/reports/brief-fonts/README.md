Fonts used when converting the sector brief decks to PDF (see ../brief.py).

- Carlito and Caladea: metric-compatible stand-ins for Calibri and Cambria (SIL Open Font License / Apache 2.0).
- Quicksand, Newsreader and Cinzel: static instances of the Google Fonts variable fonts, named so LibreOffice matches the deck's font names such as "Quicksand SemiBold" and "Newsreader SemiBold" (SIL Open Font License).
